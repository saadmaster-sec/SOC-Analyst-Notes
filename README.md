# SOC Analyst Notes and Labs

A personal learning repository documenting my progress toward entry-level Security Operations Center (SOC) analyst roles through structured notes, investigation workflows, and hands-on practice.

## Goals

- Build a strong foundation in security operations and incident response.
- Learn to triage alerts, investigate evidence, and document findings clearly.
- Practise using security tools and interpreting logs.
- Turn course learning and lab work into concise, interview-ready explanations.
- Track progress from fundamentals to practical investigations.

## Learning Method

For each topic, I aim to capture:

1. **Definition** — explain the concept in my own words.
2. **Purpose** — why it matters to security operations.
3. **How it works** — key steps, components, or workflow.
4. **Practical example** — a scenario, log, command, or lab where appropriate.
5. **Analyst perspective** — evidence to inspect, decisions to make, and limitations.
6. **Interview practice** — questions and concise explanations.
7. **Key takeaways** — the main points to remember.

Not every note needs every section. Short reference topics will stay concise; investigation reports will include more detail.

## Practical Case Study Standard

Hands-on write-ups should explain the objective, evidence reviewed, investigation steps, findings, verdict, recommended actions, and lessons learned. Only publish material that is appropriate to share. Do not commit credentials, API keys, personal information, or confidential logs. Respect course and platform rules; write original summaries instead of reproducing protected course content.

This repository is for educational and portfolio purposes. Lab findings are limited to the environments and evidence described in each write-up. Recommendations should be applied only with appropriate authorization.
